Captura de ventas

Captura la venta real de cada ejecutivo al cerrar el mes. Al aplicarla, el presupuesto se recalcula con ese mes incluido y los 12 meses del presupuesto avanzan un mes. También sirve para llenar un dato que faltaba.

Publicar para todos

Lo que capturas y ajustas aquí solo lo ves tú hasta que lo publiques. Presiona Publicar ahora y el archivo, cifrado, se guarda directo en GitHub sin descargar nada; en uno o dos minutos todos verán lo mismo.
Si escribes una nueva (mínimo 10 caracteres), el archivo se cifra con ella y desde la próxima publicación todos deberán usarla.
Conexión con GitHub (una sola vez)
El token se guarda únicamente en este navegador. Créalo en GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. Elige solo este repositorio y, en Repository permissions, Contents: Read and write.
Si prefieres no conectar GitHub, usa “Descargar datos.js” y súbelo en Add file → Upload files.

Copiar al CRM

Copia los presupuestos tal como quedan, con tus ajustes manuales, y pégalos en el CRM o en Excel. Los números van en pesos enteros, sin signo ni comas.
Si el botón no copia por restricciones del navegador, selecciona el texto de este recuadro (Ctrl+A) y cópialo con Ctrl+C. “Solo los importes” copia una columna con los mismos ejecutivos en el orden del libro, para pegarla junto a una lista que ya tengas.

Cómo se calcula

1. Base del mismo mes

Si el mes de hace 2 años vendió más que el de hace 1 año, la base es la media de los dos. Si no, la base es el año más reciente.

2. Proyección de los últimos 3 meses

Promedio de los últimos 3 meses con venta por el factor estacional del mes (cómo se comporta ese mes frente a esos 3 meses en 2024 y 2025).

3. Se toma la mayor

Si la base queda por debajo de la proyección, se usa la proyección. Así el presupuesto no cae contra el año anterior.

4. Crecimiento mínimo

Sobre esa cifra se suma el crecimiento mínimo (1%) para crecer contra el historial. Quien va en ascenso sostenido recibe un crecimiento sugerido mayor.

Ajustes del motor

Valores iniciales según tu regla. Mueve uno y se recalcula todo.

Respaldo

Tus ajustes de crecimiento y las ventas capturadas viven en este navegador. Descarga un respaldo para guardarlo o llevarlo a otra computadora, y cárgalo ahí para continuar.
